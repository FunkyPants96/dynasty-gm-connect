# Dynasty GM verbinden

Zustimmungsseite für den Connector Dynasty GM in der Claude-App, auf GitHub Pages unter
https://funkypants96.github.io/dynasty-gm-connect/connector/.

Supabase Auth leitet beim Verbinden hierher. Du meldest dich mit deinem Konto der App an und erlaubst der Claude-App
den Zugriff. Die Seite enthält keinen Schlüssel: Adresse und öffentlichen Schlüssel holt sie bei der Funktion
`gm-connector`. Die Vorlage liegt im privaten Repo unter `connector/index.html`.
